Task: Given a table of user clicks and a table of purchases, 
write a query to identify the "Last-Touch" marketing campaign for every purchase within a 7-day lookback window.

Focus: Use of LEAD/LAG, ROW_NUMBER(), and efficient join predicates.

clicks:

user_id
click_time
campaign_id
campaign_name


purchases:

user_id
purchase_time
purchase_id

---------------------------


SELECT
	p.user_id,
	p.purchase_id
FROM purchases p
JOIN clicks c
 on p.user_id = c.user_id
WHERE c.campaign_name = 'Last-Touch"
 AND DATEDIFF(date(c.click_time), date(p.purchase_time)) <= 7
